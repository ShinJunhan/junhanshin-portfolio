# AWS service icons

Drop official AWS Architecture Icons here as SVGs named to match each
service slug below, and the "Cloud (AWS)" widget on the site will pick
them up automatically — no code changes needed. While a file is missing,
a simple hand-drawn placeholder glyph is shown instead.

| File to add        | Service   |
| ------------------- | --------- |
| `ec2.svg`           | EC2       |
| `s3.svg`             | S3        |
| `vpc.svg`            | VPC       |
| `route53.svg`        | Route 53  |
| `alb.svg`             | ALB       |
| `rds.svg`             | RDS       |
| `iam.svg`             | IAM       |
| `cloudwatch.svg`      | CloudWatch|
| `dynamodb.svg`        | DynamoDB  |
| `lambda.svg`          | Lambda    |

Where to get them: AWS publishes a free "AWS Architecture Icons" asset
pack (search "AWS Architecture Icons" on the AWS website) under AWS's
icon usage guidelines. Download the pack, pull the service icon you want
from the `Arch_Service-Icons` (or `Resource-Icons`) folder for each
service above, and save it here under the matching filename — square,
transparent-background SVGs work best since they're rendered at 24×24px.
