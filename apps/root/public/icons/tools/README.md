# Tool icons (non-AWS skills)

Same mechanism as `public/icons/aws/` — drop a real SVG here named to
match a slug below, and the Skills section's icon circles pick it up
automatically. While a file is missing, a hand-drawn placeholder glyph
is shown instead.

| File to add            | Tool               |
| ----------------------- | ------------------ |
| `terraform.svg`         | Terraform           |
| `ansible.svg`           | Ansible              |
| `docker.svg`            | Docker               |
| `kubernetes.svg`        | Kubernetes           |
| `helm.svg`              | Helm                 |
| `keda.svg`              | KEDA                 |
| `karpenter.svg`         | Karpenter             |
| `eks.svg`               | EKS                    |
| `github-actions.svg`    | GitHub Actions         |
| `jenkins.svg`           | Jenkins                |
| `argocd.svg`            | ArgoCD                 |
| `gitea.svg`             | Gitea                   |
| `prometheus.svg`        | Prometheus              |
| `grafana.svg`           | Grafana                  |
| `alertmanager.svg`      | AlertManager              |

Square, transparent-background SVGs work best.
